# 👤 ইউজার অথেন্টিকেশন ও গেস্ট/ট্রায়াল ফানেল (Guest Trial & User Onboarding Flow)

> **ইউজার বৃদ্ধির মূল স্ট্র্যাটেজি (High User Acquisition):**  
> প্রথম দেখাতেই বাধ্যতামূলক লগইন চাইলে ৫০-৭০% ইউজার অ্যাপ আনইনস্টল করে ফেলে। তাই আমাদের অ্যাপে **"Zero-Friction Guest Trial"** মেকানিজম থাকবে — যাতে যেকোনো নতুন ভিজিটর সরাসরি হোম পেজ দেখতে পারে, ট্রায়াল কুইজ খেলতে পারে এবং অ্যাপের প্রিমিয়াম কোয়ালিটি দেখে মুগ্ধ হয়ে পরবর্তীতে অ্যাকাউন্ট খোলে।

## 🧭 ১. ভিজিটর ও গেস্ট ফানেল জার্নি (User Journey Flow)

```text
[ইউজার অ্যাপ ইনস্টল ও ওপেন করল]
         │
         ▼
[সরাসরি হোম ড্যাশবোর্ডে প্রবেশ]  ──► (কোনো জোরপূর্বক সাইনআপ নেই)
  • অ্যানিমেশন, গতকালের বিজয়ী ও গিফট দেখতে পাবে
  • আজকের ডেইলি কুইজের ট্রায়াল/ডেমো খেলতে পারবে
  • চ্যাপ্টারের প্রথম ১-২টি অধ্যায় প্র্যাকটিস করতে পারবে
         │
         ▼
[পার্মানেন্ট অ্যাকাউন্ট খোলার ট্রিগার পয়েন্ট]
  1. ট্রায়াল কুইজ শেষে যখন স্কোর ও কয়েন সেভ করতে চাইবে
  2. ডেইলি লিডারবোর্ডে নাম তুলে রিয়েল গিফট জেতার জন্য
  3. স্ট্রিক (Daily Streak) ধরে রাখার জন্য
  4. লক করা অ্যাডভান্সড চ্যাপ্টার আনলক করার জন্য
         │
         ▼
[১-ট্যাপে সাইন ইন (1-Tap Fast Authentication)]
  • Google Sign-In (এক ক্লিকে জিমেইল কানেক্ট)
  • Phone OTP / WhatsApp OTP
  • Apple Sign-In (iOS ইউজারদের জন্য)
         │
         ▼
[গেস্ট ডেটা অটোমেটিক মার্জ (Seamless Data Migration)]
  • গেস্টে অর্জিত কয়েন ও স্ট্রিক স্বয়ংক্রিয়ভাবে নতুন অ্যাকাউন্টে যুক্ত হবে!
```

## 🔑 ৪. টেকনিক্যাল বাস্তবায়ন (Implementation Details)

1. **Firebase Anonymous Authentication:**
   * অ্যাপ ওপেন হলেই ব্যাকগ্রাউন্ডে একটি ইউনিক `Anonymous User UID` তৈরি হবে।
   * ইউজারের লোকাল ট্রায়াল স্কোর এই টেম্পোরারি UID-এর সাথে অ্যাসাইন থাকবে।
2. **Account Linking:**
   * ইউজার যখন Google বা Phone দিয়ে সাইন-ইন করবে, তখন `linkWithCredential()` মেথড দিয়ে অ্যানোনিমাস ডেটা পার্মানেন্ট অ্যাকাউন্টের সাথে জুড়ে যাবে। কোনো ডেটা লস হবে না।
3. **লোকাল ক্যাশিং:**
   * `SharedPreferences`-এ `isGuest: true/false` ফ্ল্যাগ রাখা হবে।
