# 🛡️ অ্যাডমিন প্যানেল ও ব্যাকএন্ড আর্কিটেকচার (Admin Panel & Backend Architecture)

সম্পূর্ণ অ্যাপটি ডায়নামিক্যালি নিয়ন্ত্রণ করার জন্য একটি শক্তিশালী **Admin Web Dashboard** এবং **Backend API Engine** থাকবে। 

---

## 🖥️ অ্যাডমিন প্যানেলের পেজ ও কন্ট্রোল ফিচারসমূহ (Admin Screens)

### ১. Admin Overview Dashboard (অ্যাডমিন ড্যাশবোর্ড)
* **লাইভ মেট্রিক্স:**
  * মোট রেজিস্টার্ড ইউজার বনাম গেস্ট/ট্রায়াল ভিজিটর সংখ্যা।
  * আজকের ডেইলি কুইজে মোট অংশগ্রহণকারী সংখ্যা।
  * অ্যাক্টিভ চ্যাপ্টার ও মোট প্রশ্নের সংখ্যা।
  * পেন্ডিং গিফট রিডিম রিকোয়েস্ট কাউন্ট।
* **কুইক অ্যাকশন বাটন্স:**
  * "Publish Tomorrow's Daily Quiz"
  * "Declare Yesterday's Champions"
  * "Send In-App Notification / Broadcast Message"

---

### ২. Question Bank & Chapter Manager (কোশ্চেন ব্যাংক কন্ট্রোল)
* **চ্যাপ্টার ম্যানেজমেন্ট:**
  * নতুন বিষয় (Category) ও অধ্যায় (Chapter) তৈরি/এডিট/ডিলিট করা।
  * অধ্যায়ের ক্রম ও আইকন পরিবর্তন করা।
* **প্রশ্ন আপলোডার ও এডিটর:**
  * সরাসরি ফর্ম পূরণ করে একক প্রশ্ন যোগ করা (বাংলা ও ইংরেজি টেক্সট, ৪টি অপশন, সঠিক উত্তর, ব্যাখ্যা, ছবি)।
  * **Bulk JSON / Excel CSV Upload:** এক ক্লিকে ১০০+ প্রশ্ন JSON/Excel ফাইলের মাধ্যমে আপলোড করা।
  * প্রশ্ন প্রিভিউ ও লাইভ সার্চ/ফিল্টার (বিষয় অনুযায়ী)।

---

### ৩. Daily Quiz Scheduler (ডেইলি কুইজ শিডিউলার)
* প্রতিদিনের নির্দিষ্ট ১০টি প্রশ্ন আগে থেকেই ক্যালেন্ডার অনুযায়ী শিডিউল করে রাখা (যেমন: আগামী ৭ বা ৩০ দিনের কুইজ একসাথে রেডি রাখা)।
* প্রতিদিন রাত ১২:০০ টায় (00:00 AM) স্বয়ংক্রিয়ভাবে নতুন ১০টি প্রশ্ন লাইভ হওয়া।
* লাইভ কুইজ চলাকালীন প্রশ্ন পরিবর্তন বা সংশোধন করার সুবিধা।

---

### ৪. Winner & Gift Distribution Engine (বিজয়ী ঘোষণা ও গিফট কন্ট্রোল)
* **অটোমেটিক / ম্যানুয়াল স্ন্যাপশট:** প্রতিদিন রাত ১১:৫৯ মিনিটে সর্বোচ্চ স্কোর ও দ্রুততম সময়ের ভিত্তিতে ১ম, ২য় ও ৩য় বিজয়ী নির্বাচন।
* **উপহার নির্ধারণ:**
  * ১ম পুরস্কার (যেমন: Smartwatch / T-Shirt / Cash Voucher Code / 1000 Coins)
  * ২য় পুরস্কার (যেমন: ₹500 Amazon Gift Card / 500 Coins)
  * ৩য় পুরস্কার (যেমন: Pro Badge + 300 Coins)
* **ফিজিক্যাল গিফট কুরিয়ার ট্র্যাকার:**
  * বিজয়ীর দেওয়া নাম, মোবাইল নম্বর ও কুরিয়ার অ্যাড্রেস দেখা।
  * স্ট্যাটাস আপডেট করা: `Pending` ➔ `Shipped (কুরিয়ার ট্র্যাকিং নম্বর সহ)` ➔ `Delivered`।

---

### ৫. User & Anti-Cheat Management (ইউজার ও চিটিং মনিটর)
* রেজিস্টার্ড ও গেস্ট ইউজারদের তালিকা ও প্রোফাইল ডেটা।
* সাসপেক্টেড চিটার ফ্ল্যাগিং (যাঁরা অস্বাভাবিক দ্রুত সময়ে সব সঠিক উত্তর দেয়)।
* ফেক অ্যাকাউন্ট বা চিটার ইউজারকে ব্যান/ব্লক করার সুইচ।

---

### ৬. App Settings & Maintenance (অ্যাপ কনফিগারেশন)
* কয়েন/জেম রিওয়ার্ড রেট পরিবর্তন করা।
* মেইনটেন্যান্স মোড (Maintenance Mode) অন/অফ সুইচ (অ্যাপে "Under Maintenance" স্ক্রিন দেখানো)।
* নতুন অ্যাপ আপডেট নোটিশ পপ-আপ পাঠানো (Force Update Toggle)।

## 🗄️ ব্যাকএন্ড টেকনোলজি ও API ডিজাইন (Backend Stack & APIs)

### প্রস্তাবিত ব্যাকএন্ড স্ট্যাক (Best Choice):
* **অপশন ১ (সবচেয়ে দ্রুত ও স্কেলেবল):** **Firebase (Firestore + Firebase Auth + Cloud Functions + Firebase Storage + Hosting)**
  * সার্ভার মেইনটেন্যান্সের ঝামেলা নেই, রিয়েল-টাইম লিডারবোর্ড সেকেন্ডের মধ্যে সিঙ্ক হয়।
* **অপশন ২ (সম্পূর্ণ কাস্টম):** **Node.js / Express + MongoDB / PostgreSQL**
  * নিজস্ব VPS হোস্টিংয়ে ডিপ্লয়যোগ্য।

### 🌐 প্রধান REST API / Backend এন্ডপয়েন্টস:

| মেথড | API এন্ডপয়েন্ট | কাজ |
|---|---|---|
| `GET` | `/api/v1/app/config` | অ্যাপ সেটিংস, কারেন্ট ভার্সন ও ব্যানার ডেটা |
| `GET` | `/api/v1/guest/init` | গেস্ট ইউজারের টেম্পোরারি সেশন ও ট্রায়াল টোকেন তৈরি |
| `POST` | `/api/v1/auth/upgrade-account` | গেস্ট অ্যাকাউন্টকে পার্মানেন্ট Google/Phone অ্যাকাউন্টে রূপান্তর |
| `GET` | `/api/v1/quiz/daily/today` | আজকের ডেইলি ১০টি প্রশ্ন ফেচ করা |
| `POST` | `/api/v1/quiz/daily/submit` | ডেইলি কুইজের উত্তর সাবমিট ও স্কোর ভ্যালিডেশন |
| `GET` | `/api/v1/champions/yesterday` | গতকালের বিজয়ীদের তালিকা ও তাঁদের গিফট হিস্ট্রি |
| `GET` | `/api/v1/leaderboard/live` | আজকের লাইভ লিডারবোর্ড র‍্যাংকিং |
| `POST` | `/api/v1/gifts/claim` | বিজয়ী ইউজারের কুরিয়ার ঠিকানা সাবমিট করা |
| `POST` | `/api/v1/admin/questions/upload` | অ্যাডমিন কর্তৃক চ্যাপ্টার/ডেইলি প্রশ্ন আপলোড (JSON/CSV) |
| `POST` | `/api/v1/admin/gifts/update-status` | গিফট ডেলিভারি স্ট্যাটাস আপডেট করা |
